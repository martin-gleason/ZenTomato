# ZenPom Instructions

## What is ZenPom?
ZenPom is a [Pomodoro Timer](https://www.todoist.com/productivity-methods/pomodoro-technique). This is specifically built to work with the amazing to-do list app, [Todoist](https://www.todoist.com/), but it is not necessary. 

## What’s a Pomodoro Timer?
A Pomodoro timer sets of timed “blocks” to focus on a task (or tasks). Between each focus block is a break, a short period of time to stretch your legs, hydrate, or just chill. After a number of focus and resting blocks, there is a longer break where you can reward yourself for getting something done. One full set of this is a Pomodoro!

Here’s the trick to the Pomodoro method: once the timer starts, it doesn’t stop. The goal is to focus on getting something done in the focus block — and to break at the end of each focus block.

### So what’s with these two buttons, External and Internal
Life in the 21st century is a bombardment of notifications: Email, calendar invites, text messages, any app with a push notification — all of that leads to distractions. Add that to any worries and anxieties, and it is no wonder that the average attention span has collapsed.

ZenPom lets you address those external(Barking dogs, Phone calls, notifications) and internal distractions (worries about another project, feeling board about the current task) by clicking either button. At the end of the focus sprint you can write a sentence to summarize the distraction. This way, you can note the distraction without giving into the tempatation of breaking your focus sprint!
