The test fails if the real number EXCEEDS this one. At zero that means any delta ratified from now on

HOW THE COUNT WORKS, AND WHY IT NEEDS NO MAINTENANCE
A delta owes an amendment when the text it says the spec CURRENTLY says is still present in SPEC.md.
Apply the amendment and that text is gone, so the delta stops being counted on the next run. There is
no list to keep in step. D2 was the first confirmation: applying it dropped the count from six to five
with nothing edited but the spec itself.
