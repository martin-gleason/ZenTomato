HOW THE COUNT WORKS, AND WHY IT NEEDS NO MAINTENANCE
A delta owes an amendment when the text it says the spec CURRENTLY says is still present in SPEC.md.
Apply the amendment and that text is gone, so the delta stops being counted on the next run. There is
no list to keep in step.

The test fails if the real number EXCEEDS this one, so the backlog may shrink or hold but never grow:
ratifying a new amendment without applying it fails the build immediately. Lower this number as you
work through them. Never raise it — raising it is the act this file exists to make visible.
